## Problems and notes
- No HTTP errors on the data requests that returned data; no retry/backoff messages were logged during the runs.
- The `.../dataflow/OECD.SDD.TPS/DF_TIS/1.0?references=all` structure URL returns 404; the working form is `.../dataflow/OECD.SDD.TPS/DSD_BOP@DF_TIS/1.0?references=all`.
- OECD TIS currency: the source CURRENCY field is `_Z` (not applicable); `currency` here is derived from UNIT_MEASURE (USD_EXC->USD, EUR_EXC->EUR, XDC->XDC). Filter `currency == 'USD'` for the primary series.
- OECD TIS reporters absent for Indonesia travel: e.g. CHN, MYS, SGP, SAU, KOR, THA, IND; DEU has sub-items only. These need other sources.
- BaTIS partner-side file contains aggregate/former-country reporters (e.g. ANT_F, SCG_F) and 'W'; filter before summing across partners.
- BaTIS: Indonesia's own (N) data are world totals only; partner splits are modelled (see check file). 2023-2024 are mostly IE (interpolation/extrapolation).
- Mirror-source `value` for flow_idn = balance is the negated reporter balance; credit/debit are swapped from the reporter's own labels.
